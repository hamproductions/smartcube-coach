# Feature status

Last verified 2026-08-03 against the local dev runtime, the built production artifact served at the root, and a 390 px mobile viewport. Earlier rows were verified on 2026-07-30 against the GitHub Pages artifact at the `/smartcube-coach/` subpath. Status is based on runtime behaviour, persisted data, tests, and the availability of required hardware or server infrastructure. **No row on this page has been verified against a physically paired smart cube.**

## Status definitions

- **Working**: exercised through its canonical runtime path and persisted or rendered output was inspected.
- **Partial**: a functional foundation exists, but coverage, quality, infrastructure, or the complete product loop is missing.
- **Unverified**: implementation exists but the required physical environment has not been tested.
- **Not implemented**: planned capability is absent or a non-functional surface was removed.

## Current release claim

The current application is a functional local-first prototype with working storage, simulator capture, replay, basic reconstruction editing, small typed-answer trainers, cubie-state BLD edge and corner memo exercises, and one attributed reco.nz study.

It is not a completed smart-cube coaching product and must not be represented as one until physical capture, robust reconstruction, full trainer coverage, coaching-quality validation, and longitudinal transfer are demonstrated.
